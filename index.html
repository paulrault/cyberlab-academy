À propos de CyberLab Academy

CyberLab Academy est un projet pédagogique indépendant destiné à découvrir l'administration système, les réseaux et les bonnes pratiques informatiques.

Technologies

  • HTML pour structurer les pages.
  • CSS pour l'interface responsive.
  • JavaScript pour les interactions.
  • LocalStorage pour conserver la progression.
  • GitHub Pages pour héberger le site statique.
Attention : les données de progression restent dans le navigateur. Elles ne sont pas partagées entre plusieurs appareils.
